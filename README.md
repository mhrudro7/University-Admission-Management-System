University Admission Management System is a C-based console application developed to simplify and automate the university admission process. The project demonstrates the practical implementation of Data Structures and Algorithms, particularly Doubly Linked Lists, Stack, Queue, Dynamic Memory Allocation, Searching, Insertion, and Deletion.

The system provides separate interfaces for Students and Administrators. Students can create accounts, log in securely, view university and department information, check GPA requirements and tuition fees, and submit admission applications with their academic and personal information. The system automatically determines eligible departments based on the applicant's GPA and stores submitted applications dynamically.

The Admin Panel allows administrators to update university-related information and manage applied students through operations such as adding, searching, counting, and deleting applications. Student records and admission forms are managed using dynamically allocated doubly linked lists, allowing efficient insertion, deletion, and bidirectional traversal.

The project was developed as a CSE124: Data Structure mini lab project at Daffodil International University. It focuses on applying fundamental data structure concepts to a real-world university admission scenario while maintaining a simple, menu-driven user experience.

Technologies: C, Data Structures, Doubly Linked List, Dynamic Memory Allocation, Searching & CRUD Operations.
